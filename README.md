# project-red

A Gen 1–9 **Pokémon FireRed** romhack, built headlessly on the UCDEP (CFRU/DPE) base with
HexManiacAdvance table metadata.

- Finished ROM: **`build/project-red.gba`** (+ `build/project-red.toml` for HexManiacAdvance)
- Full write-up, feature list, and rebuild instructions: **[build/README.md](build/README.md)**

**Features:** every non-legendary/non-mythical evolution line catchable before the Pokémon League ·
all Gym Leaders / Giovanni / Elite Four / Champion run 6-mon cross-gen teams with a Gen-1 ace ·
Flash no longer required (Rock Tunnel lit; Surf/Strength removal documented as HMA map-editor steps).
